# DIALOGIC TRACE

Use DIALOGIC TRACE when a living creator, author, researcher, witness, maintainer, or other relevant source remains reachable and a direct response could discriminate between explicit live models.

Core loop:

```text
PUBLIC ARTIFACT
  -> ALEX READING
  -> MODEL / HYPOTHESIS
  -> PRESSURE
  -> QUESTION
  -> SOURCE RESPONSE
  -> RESPONSE CLASSIFICATION
  -> MODEL DELTA
  -> INDEPENDENT RETEST
  -> SURVIVOR / REFUSAL / OPEN
```

Constitutional boundaries:

```text
creator response != retroactive proof
creator agreement != independent corroboration
creator disagreement != automatic falsification
current stated intent != historical intent
silence != rejection
question wording != neutral observation
```

A response may strongly establish a responder's current stated position when identity and carrier conditions are sufficient. It does not by itself establish external mathematical, historical, scientific, genealogical, or theological claims.

Prefer PRESSURE before contact. ALEX should first build a model precise enough that the source can break it.

## Required records

A DIALOGIC TRACE should preserve:

- the public artifact or prior evidence surface;
- the pre-question model;
- the exact question;
- leading-question risk;
- channel and privacy/publication boundaries;
- the response occurrence and identity status;
- response classification;
- a model delta;
- response-dependent claims;
- independently retested claims;
- residual disagreement;
- next discriminator.

## Response classes

Useful response relations include:

```text
asks
answers
clarifies_current_position
clarifies_current_intent
disputes_our_reading
confirms_our_reading
supplies_source
supplies_counterexample
opens_discriminator
claims_historical_intent
claims_authorship
claims_provenance
```

These describe what a response does. They do not automatically establish the truth of the attached claim.

## Model delta

A response is not merely appended as an interesting quotation. Record what changed:

```text
What did we believe before asking?
What exactly did they say?
Which claims changed?
Which claims did not change?
Which claims died?
Which new source paths opened?
Which claims still depend only on the response?
Which claims survived independent retest?
What remains disputed?
```

Hard law:

> **THEIR CORRECTION CHANGES OUR MODEL. IT DOES NOT CHANGE THE PAST.**

## Privacy

Private correspondence remains private unless publication or quotation permission is separately established. A private reply may legitimately choose a new research door while remaining absent from the public evidence path.

```text
private response -> discovery motive
private response != permission to publish
```

## Hostile controls

Refuse:

- agreeable-author promotion: agreement -> independent corroboration;
- retrospective-intent overwrite: current recollection -> rewrite earlier artifact;
- authority laundering: credentials -> external claims automatically true;
- leading-question contamination: embedded answer -> spontaneous confirmation;
- silence inference: unanswered -> agreement/rejection;
- private-correspondence leakage;
- creator veto: disagreement -> delete independently supported artifact interpretation.

## Seal

> **DO NOT MERELY INTERPRET A REACHABLE SOURCE. BUILD A MODEL PRECISE ENOUGH THAT THEY CAN BREAK IT.**
