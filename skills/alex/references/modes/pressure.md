# PRESSURE

Use PRESSURE when the user intentionally supplies a compressed, strange, overstrong, symbolic, or cross-domain hypothesis and wants it investigated without either dismissing it prematurely or laundering resemblance into evidence.

Core law:

> **A strange hypothesis earns promotion by surviving loss, not by accumulating resemblance.**

## Preserve the seed

Record the user's original formulation verbatim as `H0` before correcting, literalizing, or decomposing it.

```text
H0 — verbatim seed
  -> H1 — literalized, testable claim
  -> H2 — corrected survivor
  -> H3 — cross-domain survivor, if earned
```

Each transition is a descendant. Record what changed, why it changed, what was removed, and whether the prior state remains recoverable.

## Run the pressure loop

```text
CRAZY / COMPRESSED SEED
  -> LITERALIZE
  -> ATTACK
  -> NEIGHBOR SEARCH
  -> SEPARATE BRIDGES
  -> KILL OVERCLAIMS
  -> SURVIVOR
  -> PREDICT
  -> PRESSURE AGAIN
```

1. **LITERALIZE** — write the strongest exact claims that would have to be true for the seed to hold literally.
2. **ATTACK** — seek direct counterexamples, null models, chronology failures, dependency failures, impossible implications, and the simplest competing explanations.
3. **NEIGHBOR SEARCH** — find established mechanisms, observations, historical precedents, or formal structures genuinely adjacent to parts of the seed.
4. **SEPARATE BRIDGES** — keep evidence, inference, formal analogy, metaphor, symbolic reading, theological interpretation, and unresolved relation distinct.
5. **KILL OVERCLAIMS** — remove any clause that fails its strongest available discriminator. Preserve the loss in the formation trace when it materially redirected the inquiry.
6. **SURVIVOR** — state the strongest formulation still standing. It may be much weaker than H0.
7. **PREDICT** — name observations, documents, calculations, or controls that should discriminate the survivor from alternatives.
8. **PRESSURE AGAIN** — run the smallest test capable of refusing the favored survivor.

A PRESSURE run must be permitted to return `disproved` or `unresolved`. If the favored claim cannot lose, the procedure is not adversarial.

## Required pressures

Explicitly seek four categories when material:

1. **supporting precedent** — real mechanisms or observations bearing positively;
2. **direct counterexample** — evidence capable of killing the literal claim;
3. **nearest boring explanation** — the simplest plausible account of the same observations;
4. **independent-domain recurrence** — a similar structure arising for a materially different reason.

The fourth can justify analogy, compression, or a new question. It does not establish shared mechanism, genealogy, or authority by resemblance alone.

## Bridge ledger

For consequential cross-domain moves, type each bridge using the contract in `../research-receipt.md`. Useful types include:

- documented mechanism;
- documented association;
- scholarly interpretation;
- inference;
- formal analogy;
- metaphor;
- theological or symbolic interpretation;
- unresolved bridge.

Do not let a bridge inherit the evidentiary status of the node on either side merely because the relation is interesting.

## Independence and ancestry

Agreement does not prove independent corroboration. When material, inspect whether apparent sources, editions, models, OCR systems, summaries, or citations descend from the same lineage.

Use `../constitutional-hardening.md` for:

- inherited-premise checks;
- source independence;
- remove-one replay;
- absence claims;
- dependency-family pressure.

If a count, multiplicity, or apparently independent set may collapse under ancestry descent, consult the current repo-owned `RECEIPT-DESCENT-001` method before treating the count as evidentiary weight.

## Formation trace

If coincidence, failed hypotheses, discarded overclaims, or replayable operations materially shaped the path, wrap PRESSURE with `{ PEEL. SLEEP .LEEP }` using `../formation-trace.md`.

Keep:

```text
DISCOVERY TRACE != EVIDENCE PATH
```

Search motive may explain why a door opened. It does not support the conclusion by itself.

## Return shape

A durable PRESSURE receipt should preserve at minimum:

```text
SEED
LITERAL VERDICT
WHAT BROKE
WHAT SURVIVED
WHY IT SURVIVED
BRIDGE LEDGER
COUNTEREVIDENCE
NEAREST BORING EXPLANATION
NEW PREDICTIONS
RESIDUAL WEIRDNESS
NEXT DISCRIMINATOR
```

Use `../research-receipt.md` when the result needs machine-readable handoff or durable provenance.
