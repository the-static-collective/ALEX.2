# FAR-SIDE-PASS-001 — Gestalt Recursion as a Research Practice

**Date:** 2026-08-28  
**Status:** ARCHITECTURAL RESEARCH PRACTICE · NO RUNTIME CONFORMANCE CLAIM  
**Owning generative practice:** MutatedMathalModel / MMathalM vocabulary  
**Pressure and provenance owner:** ALEX  
**Calculation sidecar when useful:** Dogram  

> **DON'T SIMPLIFY THE COMPLEXITY AWAY. FIND THE SIMPLE THING THAT MAKES THE COMPLEXITY COME BACK.**

---

## 0. Decision

This design names and bounds a recurring research maneuver that has repeatedly produced useful new structure across Static Collective work.

Working name:

```text
FAR-SIDE-PASS-001
```

Descriptive family name:

```text
GESTALT RECURSION
```

The originating human instruction is approximately:

> Go back through the whole formation, Gestalt scanning back and forth in rapid recursion, meditating on the simplicity on the far side of complexity. H0: something new may become visible.

The practice is not “think harder,” “summarize again,” or “run the same analysis repeatedly.”

It is a deliberate alternation across representation, scale, direction, and abstraction, followed by compression and regeneration pressure.

Core loop:

```text
EXPAND
  <-> RELATE
  <-> COMPRESS
  <-> RE-EXPAND
  <-> COMPARE
  -> KEEP WHAT SURVIVES
  -> TEST WHAT IS ACTUALLY NEW
  -> REPEAT OR STOP
```

The target is not the shortest possible description.

The target is:

> **the smallest candidate structure that can regenerate the important complexity without silently discarding the relations that made that complexity matter.**

This document does not add a new ALEX task shape, runtime operator, Crucible schema, skill trigger, or Dogram operator.

---

## 1. Ownership split

The practice works only if generation and epistemic pressure remain separate.

### 1.1 MMathalM owns the generative maneuver

MMathalM may:

- change representational frame;
- move rapidly between whole and parts;
- reverse traversal direction;
- translate graph to algebra, algebra to graph, prose to state model, state model to prose;
- seek latent invariants;
- propose compressions;
- re-expand a proposed compression;
- generate candidate relations, mechanisms, analogies, and predictions;
- intentionally search under a novelty hypothesis.

MMathalM does **not** thereby establish:

```text
support
evidence
historical fact
shared mechanism
genealogy
authority
canon
execution rights
```

### 1.2 ALEX owns provenance and pressure

ALEX may:

- preserve the original H0 verbatim;
- baseline what was already explicit before the pass;
- receipt the transformations used during the pass;
- distinguish discovery path from evidence path;
- distinguish new wording from new derivation;
- attack candidate simplicities with null models and hostile siblings;
- test whether the candidate survives metaphor removal and representation change;
- classify what was actually added by the pass;
- refuse novelty when the candidate was already latent or merely renamed;
- return `NO NEW DIMENSION EARNED` as a successful result.

ALEX does not need to become the generative organ that is compelled to invent a far-side simplicity.

### 1.3 Dogram owns exact calculations only when a candidate earns them

Dogram may receive bounded specimens from the pass and calculate:

- deltas;
- graph residuals;
- finite differences;
- interaction rectangles;
- reachability changes;
- exact algebraic invariants;
- permutation or ablation controls.

Dogram output remains calculation receipt, not semantic promotion.

## 2. Governing non-collapse laws

Freeze these before any implementation proposal:

```text
SEARCH FOR NOVELTY != PRODUCTION OF NOVELTY
NEW WORDING != NEW REPRESENTATION
NEW REPRESENTATION != NEW DERIVATION
NEW DERIVATION != NEW RELATION
NEW RELATION != NEW INVARIANT
NEW INVARIANT != NEW PREDICTION
NOVEL-SEEMING != NOVEL
COMPRESSION != EXPLANATION
COMPRESSION != INFORMATION PRESERVATION
REGENERATION != HISTORICAL RECONSTRUCTION
ANALOGY != SHARED MECHANISM
CONVERGENCE != PROOF
FIXED POINT != TRUTH
```

The most important law is:

> **The H0 requires a search for novelty, not the production of novelty.**

The practice must be allowed to terminate with:

```text
NOVELTY_DELTA = EMPTY
```

without treating the run as a failure.

## 3. Inquiry cut and baseline

A far-side pass begins by freezing the pre-pass surface.

Minimum baseline:

```text
H0
CURRENT FORMULATIONS
CURRENT RELATIONS
CURRENT INVARIANTS
CURRENT OPEN QUESTIONS
CURRENT PREDICTIONS
KNOWN REPRESENTATIONS
STOPPING CONDITION
```

Call this baseline:

```math
B_0.
```

The baseline matters because novelty is relational.

A candidate can be new only relative to a declared prior surface.

Without `B0`, the run cannot distinguish:

```text
newly derived
from
newly noticed
from
newly worded
from
already present but forgotten.
```

For ALEX, the baseline is part of the discovery trace, not evidentiary support by itself.

## 4. The traversal family

The practice should not mean “repeat the same prompt N times.”

Each recursion should change at least one declared axis.

Recommended axes:

### 4.1 Scale

```text
WHOLE -> PARTS
PARTS -> WHOLE
LOCAL -> GLOBAL
GLOBAL -> LOCAL
```

### 4.2 Direction

```text
FORMATION -> RESULT
RESULT -> FORMATION
CAUSE-CANDIDATE -> CONSEQUENCE
CONSEQUENCE -> REQUIRED PRECONDITIONS
```

### 4.3 Object / relation

```text
OBJECTS -> RELATIONS
RELATIONS -> OBJECTS
CARRIERS -> TRANSFORMS
TRANSFORMS -> REQUIRED CARRIERS
```

### 4.4 Representation

```text
PROSE <-> GRAPH
GRAPH <-> MATRIX
MATRIX <-> STATE MACHINE
STATE MACHINE <-> GEOMETRY
GEOMETRY <-> COMBINATORICS
COMBINATORICS <-> PROSE
```

No representation is privileged merely because it is mathematical.

### 4.5 Time

```text
CHRONOLOGY -> FORMATION ROLE
FORMATION ROLE -> CHRONOLOGY
CURRENT STATE -> HISTORICAL CUT
HISTORICAL CUT -> LATER REINTERPRETATION
```

### 4.6 Compression / regeneration

```text
COMPLEX SURFACE -> CANDIDATE GENERATOR
CANDIDATE GENERATOR -> REGENERATED SURFACE
```

This last axis is the defining far-side move.

## 5. Compression is not enough

Let the current complex formation be:

```math
X.
```

A candidate compression produces:

```math
C(X)=S.
```

That alone is weak.

A slogan can compress almost anything.

The candidate must be pushed in the opposite direction through an explicit regeneration map:

```math
R(S)=\hat{X}.
```

Then compare the regenerated structure with the important parts of the original:

```math
\hat{X} \sim X.
```

The equivalence relation must be declared for the run.

It may concern:

- preserved invariants;
- preserved incidence;
- preserved derivation structure;
- preserved reachable states;
- preserved predictions;
- preserved counterexamples;
- preserved formation ancestry;
- preserved output under a declared decoder.

It need not require byte-identical reconstruction.

The keeper is:

```text
GOOD SIMPLICITY
=
COMPRESSION
+
REGENERATIVE POWER.
```

A simplicity that cannot regenerate the important structure is not yet a far-side survivor.

## 6. Invariant harvesting

Let successive gestalt states be:

```math
G_0, G_1, ..., G_n
```

where each transition uses a declared transformation:

```math
G_{i+1}=T_i(G_i).
```

At each step, record candidate invariants:

```math
I_i = I(G_i,G_{i+1}).
```

The far-side candidate should preferentially compress what survives across multiple materially different transforms:

```math
I_* = \bigcap_i I_i
```

conceptually, not necessarily as literal set intersection.

This does **not** mean that recurrence across representations proves truth.

It means recurrence has earned pressure as a candidate invariant.

ALEX must still ask whether the recurrence was forced by the chosen encodings, shared construction, or a trivial identity.

## 7. Three required outputs

A successful pass returns three primary objects:

```math
(I,S,Delta)
```

### 7.1 `I` — invariant ledger

What survived multiple declared transformations?

For each invariant, preserve:

```text
statement
first seen at
representations survived
representations failed
required assumptions
counterexamples
status
```

### 7.2 `S` — far-side simplicity candidate

The smallest useful generator/model currently found.

Preserve:

```text
candidate statement
compression rule
regeneration rule
what it regenerates
what it fails to regenerate
residual complexity
losses
```

A far-side simplicity may be partial.

Partial explanatory compression is preferable to pretending a universal law.

### 7.3 `Delta` — novelty delta

What became available after the pass that was not explicit in `B0`?

Classify each novelty candidate as one of:

```text
NEW_WORDING
NEW_REPRESENTATION
NEW_DERIVATION
NEW_RELATION
NEW_INVARIANT
NEW_PREDICTION
```

These are ordered only by type, not by automatic evidentiary strength.

A new prediction may be wrong.

A new invariant may be decoder-local.

A new relation may be unsupported.

The type tells us what changed, not whether it is true.

## 8. Novelty accounting

A candidate novelty should answer:

```text
NEW RELATIVE TO WHAT?
```

Minimum ALEX comparison:

```text
BEFORE
  what was explicit?

TRANSFORM
  what operation exposed the candidate?

AFTER
  what can now be stated or predicted?

DELTA
  why is this not merely a synonym or coordinate change?
```

A useful conceptual form is:

```math
Delta = Consequences(S) - Consequences(B_0).
```

The set difference is conceptual: the point is to require a discriminable consequence delta.

Candidate novelty is stronger when it yields at least one of:

- a derivation unavailable from the old representation;
- a unification of several formerly separate observations;
- a new hostile test;
- a new prediction;
- a new failure mode;
- a new compression ratio without losing declared invariants;
- a new distinction that blocks a prior collapse.

## 9. ALEX pressure pass

Every far-side candidate must survive an adversarial sibling pass before promotion.

At minimum test:

### 9.1 Nearest boring compression

Can a simpler ordinary explanation compress the same observations?

### 9.2 Metaphor removal

Rewrite the candidate without the motivating imagery, names, sacred numbers, body metaphors, or project-local jargon.

If the structure disappears, it was not yet an ALEX-stable invariant.

### 9.3 Representation swap

Does the candidate survive a materially different encoding?

### 9.4 Permutation / relabel control

Does arbitrary relabeling preserve the claimed structure?

If yes, the semantic labels may be irrelevant.

### 9.5 Arity / field / parameter swap

When mathematics is involved, vary the parameter that appears special.

Ask whether the result is unique, generic, or accidental.

### 9.6 Holdout prediction

Can the candidate predict a structure not used to construct it?

### 9.7 Regeneration failure

Which important part of the original complexity does `S` fail to regenerate?

Preserve the failure instead of repairing it after the fact.

## 10. Relationship to existing ALEX practices

FAR-SIDE PASS does not replace PRESSURE, PEEL/SLEEP/LEEP, or UNGATE.

### PRESSURE

PRESSURE begins with a strange or overstrong hypothesis and attacks it until a survivor remains.

FAR-SIDE PASS begins with a complex formation and recursively changes representation to seek a smaller regenerative structure and a receipted novelty delta.

They may compose:

```text
FAR-SIDE candidate
  -> PRESSURE
  -> survivor / refusal
```

or:

```text
PRESSURE survivor
  -> FAR-SIDE PASS
  -> smaller generator / no-new-dimension result
```

### PEEL / SLEEP / LEEP

Formation trace preserves how the inquiry formed and whether a replay is attributable.

FAR-SIDE PASS may use PEEL to recover the complex formation before compression and may use LEEP-like replay ideas to test regeneration.

It must not collapse regenerated equivalence into historical identity.

### UNGATE

UNGATE suspends decoder rings around a nucleus to reopen reachable readings.

FAR-SIDE PASS may use a decoder change as one traversal axis, but it does not presume that older or newly reachable readings are truer.

## 12. Stopping conditions

The practice must not recurse forever merely because another representation can always be invented.

Stop when any declared condition is met, including:

```text
NO NEW INVARIANT AFTER N MATERIAL TRANSFORMS
NOVELTY DELTA EMPTY
CANDIDATE REGENERATES DECLARED TARGETS
HOSTILE TEST KILLS CANDIDATE
RESIDUAL COMPLEXITY STOPS SHRINKING
REPRESENTATION LOOP RETURNS NO NEW CONSEQUENCE
BUDGET REACHED
```

A fixed point is a stopping condition, not a truth certificate.

## 14. Runtime promotion gates

Do not implement FAR-SIDE as an ALEX runtime or skill trigger until all of the following are true:

```text
1. baseline capture can be made deterministic enough for novelty comparison;
2. at least three materially distinct traversal axes have executable specimens;
3. regeneration equivalence can be declared without one universal comparison predicate;
4. `NO_NEW_DIMENSION_EARNED` is tested as a first-class success state;
5. novelty typing survives paraphrase / relabel controls;
6. metaphor-removal and holdout controls can kill favored candidates;
7. the generator cannot mint support or authority merely by producing a compact model;
8. Dogram calculation handoffs remain optional and semantics-free;
9. replay / regeneration remains distinct from historical occurrence;
10. implementation can stay smaller than a general-purpose autonomous research loop.
```

Until then, FAR-SIDE PASS remains a research practice and design vocabulary.

---

## 15. Self-hostile questions

Before calling the practice useful, repeatedly ask:

```text
Did recursion expose something new, or merely exhaust the writer into accepting a catchy phrase?

Did the chosen representations all share the same hidden construction, making recurrence inevitable?

Was the candidate simplicity selected because it regenerates structure, or because it sounds elegant?

Could the same novelty delta be produced by one ordinary comparison pass?

Does the practice reward over-compression?

Does an explicit novelty H0 cause confirmation pressure?

Can the system return no novelty without trying to rescue the premise?

Does the candidate survive after the motivating metaphor is removed?
```

If the answer to the last two is no, the practice has failed its own constitution.
