```text
1078 / 1087
```

The conversational move was initially described as "count-boundary recursion" and "receipt descent."

The durable research name is:

```text
RECEIPT-DESCENT-001
```

The Dogram arithmetic profile is:

```text
COUNT-BOUNDARY-001
```

The method is not a claim that number coincidences reveal an external hidden mechanism.

It is a controlled way to test whether a human-perceived arithmetic path continues to survive after the available transformations are frozen and hostile controls are applied.

## 1. Core maneuver

The generative observation is:

```text
OBJECT
  ↓ derive a standard structural coordinate
RECEIPT VALUE
  ↓ reify as the next inert carrier
BOUNDARY PRESSURE
  ↓ inspect predecessor/successor when declared
NEW STRUCTURAL COORDINATE
  ↓

```

Examples of structural coordinates include:

```text

prime index p_n
divisor count τ(n)
Euler totient φ(n)
pair count C(n,2)
```

The move is therefore a special case of the already-useful architectural distinction:

```text
DERIVE != REIFY != PROMOTE
```

A numerical output may be derived without becoming the next object of inquiry. Making it the next inquiry carrier is an explicit research move.

## 2. Why freezing is constitutional

Without a frozen operator family, any finite set of integers can be connected by enough custom formulas.

Therefore:

```text
NUMERIC EQUALITY != ADMITTED EDGE
ADMITTED EDGE != IMPORTANT EDGE
IMPORTANT-LOOKING EDGE != INDEPENDENT EDGE
DENSE GRAPH != HIDDEN MECHANISM
POST-HOC FORMULA != PREDICTION
```

The method's central refusal is:

> **Do not invent a new operator because the current graph almost closes.**

A path that dies under the frozen family is informative.

## 9. Corpus pressure distinctions

A research run must separate at least four edge classes.

### 9.1 Boundary scaffold

```text
n <-> n+1
```

Adjacent pairs are often supplied deliberately, so these edges are cheap.

They support traversal but should not independently count as structural enrichment.

### 9.2 Automatic structural family

Examples:

```math
p\text{ prime} -> φ(p)=p-1
```

and:

```text
n --nth_prime--> p_n --prime_pi--> n
```

These edges are exact but partly automatic given the class membership.

### 9.3 Cross-operator convergence

Two differently typed structural operations reach one carrier.

Example:

```text
π(1078)=180=φ(181)
```

This receives more research interest because it is not simply one inverse pair counted twice.

### 9.4 Post-hoc rescue

An operator introduced only because it reaches the desired target.

Disposition:

```text
REFUSED_POST_HOC_OPERATOR
```

A new operator may be proposed for COUNT-BOUNDARY@2 only when:

1. it has an independent mathematical identity or independently stated research rationale;

3. it can produce misses;

6. old @1 runs remain replayable without reinterpretation.

No operator receives promotion solely because it closes a beloved path.

## 17. Kill conditions

Stop, narrow, or retire the method if:

- useful paths appear only after adding target-specific operators;
- matched null corpora routinely produce equivalent structure after cheap-edge discounting;
- out-of-sample tests repeatedly miss while retrospective graph density remains high;
- representation diagnostics are repeatedly laundered into traversal edges;
- operator versions are changed without preserving prior receipts;
- the method becomes unable to return `NO LAWFUL EDGE`;
- graph density is treated as evidence of external mechanism without an independent causal bridge.
