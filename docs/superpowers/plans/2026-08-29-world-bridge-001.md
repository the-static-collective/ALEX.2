# WORLD-BRIDGE-001 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a deterministic ALEX evaluator that receipts explicit A/B/C/D world crossings without converting the bridge into historical support or authority.

**Architecture:** Create one standard-library module, `alex_runtime/world_bridge.py`, with a pure `evaluate_world_bridge(record)` evaluator. It validates source/target occurrence identities, direction, bridge typing, documented-evidence requirements, and promotion limits, then returns deterministic `ACCEPT` or `REFUSE` receipts with `authority: none`.

**Tech Stack:** Python 3.12 standard library, `unittest`, existing `alex_runtime.digests.sha256_json`.

**Spec:** `docs/superpowers/specs/2026-08-29-world-bridge-001-design.md`

## Global Constraints

- Production runtime remains standard-library only.
- The evaluator does not fetch evidence or decide historical truth.
- A/B/C/D direction remains part of identity.
- Same-world relations are outside this profile.
- Documented bridge types require at least one well-formed evidence reference.
- Every output freezes `authority` to `none`.
