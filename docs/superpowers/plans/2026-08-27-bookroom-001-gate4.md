# BOOKROOM-001 Gate 4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first executable ALEX Book Room: one exact local PDF carrier becomes an immutable evidence floor, a separately receipted Book Model, a separately receipted Research Model, a cut-bounded context surface, a deletable/rebuildable Novelist-compatible projection, and an offline-replayable dossier with exact quote-to-page return.

**Architecture:** Keep source custody in ALEX-owned CAS + SQLite/FTS5. Book Model and Research Model are distinct append-only record families connected only by attributable loci and existing Gate-2 support evaluation. The Novelist-compatible room is a deterministic disposable projection. Gate 3 guards capabilities/effects; Gate 3.5 remains optional and is not implemented here.

**Tech Stack:** Python 3.12, standard-library `sqlite3` + FTS5, filesystem content-addressed storage, JSON/JSONL exports, `pypdfium2==5.13.0`, `Pillow==12.3.0`, existing ALEX Blind Crucible, existing `RELATION-DERIVATION-001`, merged Gate-3 LOADOUT handshake.

**Spec:** `docs/superpowers/specs/2026-08-27-bookroom-001-gate4-design.md`

## Global Constraints

- Do not begin Task 1 until Gate 3 (`alex_runtime/handshake.py`, `alex.run-envelope/v0`, LOADOUT handshake profile) is merged to `main` and the full unittest suite is green.
- Gate 3.5 formation/relation provenance is not a prerequisite and must not be reimplemented here.
- `BOOK MODEL != RESEARCH MODEL` is enforced by storage and APIs.
- `BOOK SAYS X != ALEX ASSERTS X IS TRUE`; `NOVELIST PROJECTION != EVIDENCE`; `CONTEXT SELECTION != SUPPORT` are executable refusal paths.
- One exact carrier/acquisition only for `BOOKROOM-001`; no multi-edition synthesis.
- Occurrence ID != content digest. Equal bytes may deduplicate in CAS while acquisitions/readings/model occurrences stay distinct.
- Raw bytes and page-surface bytes are immutable and content-addressed. Corrections append descendants.
- SQLite + FTS5 are the first durable indexes. No graph/vector database, server, or model provider is required.
- Never commit source corpora, scans, private research, generated room workspaces, SQLite DBs, CAS objects, credentials, or live-witness manifests.
- No local page bytes leave the machine in this implementation.
- PDF embedded text is labeled `pdf_text_layer`, never OCR/HTR. Missing text becomes `FOG`.
- A source locus binds exact carrier + canvas + reading/span + page surface. Exact quotation must resolve through a `SourceLocusRecord`.
- Book/section order is source presentation order, not causal/composition/historical chronology.
- `SUPPORTS` is evaluated only through existing `evaluate_relation_case()`. Add no `CONTRADICTS`, `SAME_AS`, genealogy, authority, or admission predicate.
- Counterevidence is an attributable research-pressure record, not a new semantic predicate.
- Evidence relation, evaluator disposition, execution state, research lifecycle, and external admission remain distinct axes.
- CI uses synthetic carriers. Gate-4 live conformance remains unclaimed until the same runtime passes one operator-supplied local 100–300-page real book.
