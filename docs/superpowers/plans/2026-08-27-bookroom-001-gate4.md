# BOOKROOM-001 Gate 4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first executable ALEX Book Room: one exact local PDF carrier becomes an immutable evidence floor, a separately receipted Book Model, a separately receipted Research Model, a cut-bounded context surface, a deletable/rebuildable Novelist-compatible projection, and an offline-replayable dossier.

**Architecture:** Keep the source/evidence core in ALEX-owned content-addressed storage plus SQLite/FTS5. Treat Book Model and Research Model as separate append-only record families joined only by attributable references and existing Gate-2 support evaluation. Generate the Novelist-compatible room as a disposable projection; deleting it must not delete evidence. Gate 3 remains the authority/capability receiving boundary; Gate 3.5 is optional and is not implemented by this plan.

**Tech Stack:** Python 3.12, standard-library `sqlite3` + FTS5, filesystem content-addressed storage, JSON/JSONL durable exports, `pypdfium2==5.13.0`, `Pillow==12.3.0`, existing ALEX Blind Crucible and `RELATION-DERIVATION-001` runtime.

**Spec:** `docs/superpowers/specs/2026-08-27-bookroom-001-gate4-design.md`

## Global Constraints

- Do not start Task 1 until Gate 3 (`alex_runtime/handshake.py`, `alex.run-envelope/v0`, and the LOADOUT handshake profile) is merged to `main` with the full repository unittest suite green.
- Gate 3.5 formation/relation provenance remains a candidate seam. No task in this plan may require Gate 3.5 to exist.
- `BOOK MODEL != RESEARCH MODEL` is a storage and API invariant, not documentation-only guidance.
- `BOOK SAYS X != ALEX ASSERTS X IS TRUE` and `NOVELIST PROJECTION != EVIDENCE` must be executable refusal paths.
- One exact carrier/acquisition only for `BOOKROOM-001`; no multi-edition synthesis.
- Occurrence identity is never derived from content digest. Equal bytes may deduplicate in CAS while acquisition/reading/model occurrence IDs remain distinct.
- Raw held bytes are immutable and content-addressed. Corrections append descendants; they never overwrite prior readings.
- SQLite + FTS5 are the first durable index. No graph database, vector database, server, or external model is required.
- No source corpus, copyrighted scan, private research material, or credentials may be committed to Git.
- No local page bytes may leave the machine without an existing Gate-3-authorized effect plus an explicit egress receipt; this plan implements no external-model egress path.
- Text extracted from a PDF text layer must be labeled `pdf_text_layer`; it must never be described as OCR/HTR.
- Missing or unusable text is `FOG`, not an invented reading.
- Book/section order is a source presentation coordinate. It does not mint causal, composition, or historical chronology.
- Context inclusion explains what was available to a run; `context selection != evidence`.
- Semantic `SUPPORTS` is evaluated only by the existing Gate-2 `evaluate_relation_case()` path. This plan adds no `CONTRADICTS`, `SAME_AS`, genealogy, authority, or admission predicate.
- Counterevidence is stored as an attributable research-pressure record, not silently promoted into a new semantic predicate.
- Evaluator disposition, execution state, evidence relations, research lifecycle, and external admission stay separate.
- CI uses deterministic synthetic carriers only. Gate-4 conformance remains unclaimed until the live witness runner passes against one operator-supplied, locally held, 100–300-page real book.
