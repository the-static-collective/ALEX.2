# NAME-NULLS-001 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an executable ALEX gate that refuses incomplete or internally contradictory NAME hostile-control batteries.

**Architecture:** Add `alex_runtime/name_nulls.py` with pure `evaluate_name_null_battery(record)` validation. Runtime validates a fixed six-control v0 family, exact hypothesis/target references, one changed dimension per attributable control, preserved-invariant consistency, executor ownership, and deterministic identity; it never evaluates whether the favored hypothesis survived.

**Tech Stack:** Python 3.12 standard library, `unittest`, existing canonical JSON digest helper.

**Spec:** `docs/superpowers/specs/2026-08-29-name-nulls-001-design.md`

## Global Constraints

- Standard library only.
- Exactly one control of each required v0 type.
- No favored result or expected answer is stored in the battery.
- Structural acceptance is not hypothesis survival.
- Every output freezes authority to `none`.
