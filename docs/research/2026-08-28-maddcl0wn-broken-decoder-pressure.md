## 1. Why MADDCL0WN exists

Ordinary decoder analysis often asks:

> Which decoder is correct?

That question is sometimes premature.

Before selecting a decoder, ALEX may learn something useful by asking:

> **What changes when the key changes?**

A decoder can be treated as an attributable research condition.

If controlled perturbation of one decoder feature destroys a result, that feature is load-bearing for the result under the tested conditions.

If a result survives several materially different decoder perturbations, it becomes an invariant candidate.

If two decoder changes interact, the interaction itself becomes a pressure target.

MADDCL0WN is therefore a research wrapper for **controlled decoder breakage**.

It does not grant broken decoders evidentiary authority.

## 14. Stateful return vs fake holonomy

A particularly important pressure result emerged while formalizing the ring idea.

For a pure deterministic stateless decoder:

```math

```

if a traversal returns to the exact same source `x` and exact same decoder constitution `D`, the projection must return too.

Therefore:

> **NO HIDDEN HISTORY, NO NONZERO HOLONOMY.**

A claimed changed return means something else changed:

```text
source
decoder state
context
history
randomness
implementation

```

If history really is constitutive, model it explicitly:

```math
M(x,D,H).
```

Then a path may return to `D0` while ending with:

```text

```

and a changed projection may be attributable to formation history.

ALEX should classify this as a history/context effect, not mystical resonance.
