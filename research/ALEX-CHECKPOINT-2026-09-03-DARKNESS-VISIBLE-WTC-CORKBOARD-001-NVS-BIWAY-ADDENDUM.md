## Finding

A useful refinement emerged from replaying the current corkboard without taking declared identity, ideology, title, friendship, or institutional branding as the primary analytic surface.

The primitive is:

```text
NAME ↔ VERB ↔ SYSTEM
```

More precisely:

```text
N_from --V--> N_to @ S
```

A **Name** is an attributable node.  
A **Verb** is an attributable transformation, handoff, constraint, or action between nodes.  
A **System** is the bounded field in which that verb is possible and consequential.

The graph is **biway** because it must be readable in both directions:

```text
NAME -> VERB -> SYSTEM
SYSTEM -> afforded/constrained VERB -> NAME
```

and relationally:

```text
N_i --V--> N_j @ S
N_j --V'--> N_i @ S
```

The reverse verb need not equal the forward verb.

The method therefore asks less:

> Who does this person say they are?

and more:

> What attributable verbs move to and from this name, through which systems, at what time, with which receipts?

This is a research grammar only. It does not infer covert coordination from similar movement.

```text
CONVENER

```

A functional name is a compression of receipts. It is not a hidden essence.

Promotion law:

```text
repeated verbs -> candidate functional name
candidate functional name != fact about motive
candidate functional name != covert role
```

# 2. RED LINES REQUIRE VERBS

A social graph edge without a typed relation has almost no evidentiary value.

```text
A --- B
```

must be replaced, where possible, with:

```text
A --appoints--> B
A --funds--> B
A --investigates--> B
A --represents--> B
A --convenes--> B
A --reports-to--> B
A --authorizes--> B
A --inherits-from--> B
A --closes-investigation-of--> B
```

The verbs are non-interchangeable:

```text
KNOWS
!= FUNDS
!= APPOINTS
!= INVESTIGATES
!= REPRESENTS
!= CONVENES
!= REPORTS TO
!= AUTHORIZES
!= INHERITS FROM
!= CLOSES FOR
```

Whenever only `KNOWS`, `FRIEND OF`, `ASSOCIATED WITH`, or `CONNECTED TO` is recoverable, retain that weak verb rather than silently upgrading it.

# 3. EDGE OBJECT

Minimal attributable edge:

```text
E = (N_from, V, N_to, S, t, R)
```

where:

- `N_from` — source Name;
- `V` — typed observed verb;
- `N_to` — receiving Name;
- `S` — system/aperture in which the verb operates;
- `t` — event time or bounded interval;
- `R` — receipt set / provenance pointer.

Optional pressure fields:

```text
A = authority possessed
C = capability possessed
O = observed consequence
K = known-at / availability state
Q = confidence / provenance quality
```

Expanded edge when needed:

```text
E* = (N_from, V, N_to, S, t, R, A, C, O, K, Q)
```

Constitutional floor:

```text
receipt != interpretation != claim
relation != capability
capability != authority
authority != action
action != causation
```

# 4. ASK WHAT NAMES THEY VERB TO AND FROM

For a Name `N`, inspect the typed local neighborhood rather than merely counting adjacency.

```text
Γ(N) = {
  (N_i, V_in, N),
  (N, V_out, N_j)
}
```

Incoming questions:

```text
Who appoints N?
Who funds N?
Who informs N?
Who introduces N?
Who investigates N?
Who represents N?
Who protects N under an attributable mechanism?
Who transfers authority/custody to N?
```

Outgoing questions:

```text
Whom does N appoint?
Whom does N fund?
Whom does N investigate?
Whom does N represent?
Whom does N convene?
Whom does N authorize?
Whom does N replace?
Whose matter does N close?
To whom does N transfer information, custody, capital, or authority?
```

The interesting object is often the **verb distribution**.

```text
A --reports-to--> X
B --reports-to--> X
C --reports-to--> X
```

may support a candidate `GATE` function.

```text
X --introduces--> A
X --introduces--> B
X --introduces--> C
```

may support a candidate `BROKER` function.

```text
A --investigates--> X
B --investigates--> X
C --investigates--> X
```

may identify `X` as an exposure node.

```text
X --closes--> A
X --closes--> B
X --closes--> C
```

may support a candidate `CLOSURE OPERATOR` function.

None of these patterns establishes motive or conspiracy by itself.

# 6. BIWAY READING

Forward reading:

```text
NAME --does--> VERB --within--> SYSTEM
```

Backward reading:

```text
SYSTEM --affords/constrains--> VERB --reveals--> NAME
```

This permits two complementary searches.

### Name-first

```text
N -> outgoing/incoming verbs -> systems -> neighboring names
```

### System-first

```text
S -> recurring verbs -> names occupying those verbs -> handoffs between names
```

The second route is especially useful where partisan, corporate, religious, or institutional labels obscure a shared operating field.

Firewall:

```text
shared system != shared intent
complementary verbs != coordination
coordination != causation
```

# 7. DYADS AS COMPLEMENTARY VERB PAIRS

A dyad is useful only when the complementary function is documented.

Do not promote:

```text
PERSON 1 + PERSON 2 -> hidden pair
```

Instead type:

```text
N_1 --V_12--> N_2 @ S
N_2 --V_21--> N_1 @ S
```

Then compare capability vectors:

```text
formal authority
operational capability
information access
relationship-routing power
```

A possible higher-order dyad object may be proposed only if the pair repeatedly composes a stable function supported by receipts.

```text
DYAD != SAME ROLE
DYAD != SAME INTENT
DYAD != SECRET COMMAND
```

# 8. LAYERED TRINARY EMERGENCE

The grammar is recursive.

At layer `k`:

```text
L_k = (N_k, V_k, S_k)
```

Lower layer specimen:

```text
person --introduces--> person @ institution
person --appoints--> person @ institution
person --funds--> person @ political/economic system
```

If a lower-level relation pattern is stable enough to be useful as an attributable analytical carrier, it may be **lifted** into a higher-order Name:

```text
Λ : (N_k, V_k, S_k) -> (N_{k+1}, V_{k+1}, S_{k+1})
```

Example abstraction:

```text
individual people/actions/institutions
        ↓ Λ
coalitions / networks / institutional behaviors
        ↓ Λ
political-economic ecosystems / carrier ecologies
```

The same trinary then runs again:

```text
N_1 ↔ V_1 ↔ S_1
N_2 ↔ V_2 ↔ S_2
...
```

Thus a sufficiently coherent lower-level **System** may become a higher-level **Name**, while repeated lower-level verbs may support a candidate higher-level Verb.

Example:

```text
A --introduces--> B
B --appoints--> C
C --funds--> D
D --reports-to--> A
```

may, after pressure and receipt checks, support a higher-level description such as:

```text
NETWORK X --recruits/reproduces--> NETWORK X
```

The macro-verb must remain reducible to the micro-verbs that generated it.

# 9. RECEIPTS MUST POINT DOWNWARD

Every lift carries a descent path:

```text
N_2
 -> constituent N_1 objects
 -> constituent N_0 objects
 -> typed edges
 -> receipts
```

A higher-level statement that cannot descend to its receipts is narrative compression, not a lawful ALEX carrier.

Required promotion record for an emergent Name:

```text
candidate higher Name
constituent lower Names
constitutive typed verbs
systems crossed
bounded time window
receipt set
alternative decompositions
promotion status
```

Required refusal condition:

```text
If the macro-node requires replacing missing verbs with motive,
refuse promotion.
```

# 10. EMERGENCE FIREWALL

The central law:

```text
EMERGENT COHERENCE != CENTRALIZED INTENT
```

A distributed system may exhibit coherent macro-behavior without every node possessing global awareness.

Therefore:

```text
coherent macro-pattern
!= command hierarchy
!= shared secret
!= conspiracy
```

The grammar is intended specifically to make distributed behavior visible **without manufacturing a controller**.

This is the bridge to the earlier carrier-network work: movements, bureaucracies, markets, political machines, religious organizations, corporations, public authorities, professional networks, and criminal organizations can all generate superficially similar functional shapes. The shape alone does not identify the species.

Species must be established independently.
