# MOTIF — Learning What Opens the Next Door

**Frontier research harvest · November 4, 2026, America/Chicago**  
**Status: source-grounded synthesis and proposed experiments. No project adoption.**

The strongest direction uncovered in this pass is an intelligence that learns **how interventions change available capabilities, and what evidence it needs when that prediction fails**.

MOTIF already has a small executable foothold. The surrounding work supplies unusually relevant material on observer limits, representation loss, negative evidence, portable capabilities, and narrative consequence. These connections justify a research program. They do not establish a new general intelligence architecture.

This dossier gathers the nearby notes, distinguishes documented ancestry from resemblance, checks the present MOTIF experiments, and proposes a discriminating next study. It is a broad first harvest of connected sources, not an exhaustive search of every conversation, branch, repository, or private drive.

### The older MOTIF deserves its own distinction

[Project0 PR #18](https://github.com/the-static-collective/project0/pull/18) contains a design at head **37f7c70ec38df9199189127c27e077f63cac1d24**:

Source particular → rupture → tension → response → anchor state → recognition → successor source.

It describes a motif as an evidence-bearing relational history, with a compressed signature used only to retrieve candidates. Recognition can accept, refuse, remain uncertain, or identify a novel but continuous descendant.

This is a strong conceptual neighbor of today's transform-learning MOTIF. The older design asks whether a transformation preserves a particular lineage; the newer experiments ask which transformations can be induced and what they enable. Their composition is a candidate bridge, not a discovered implementation dependency.

A useful future experiment would require both **mechanical transfer** and **source-recognized continuity**, scoring them separately.

## The new synthesis: an affordance model with a research policy

**Proposed synthesis:** model the field, the actor's available knowledge, and the action frontier separately. Learn not only predicted outcomes but which additional evidence would make those predictions more reliable.

There are several different reasons a future can become unavailable:

| Change | What actually changed? | Correct response might be |
|---|---|---|
| Tool breaks | Physical/execution capability | Repair, replace or choose another route |
| Time window closes | Feasibility under duration | Replan or abstain |
| Observer lacks a fact | Knowledge about a possibly existing route | Inspect or ask |
| Permission is absent/revoked | Admissible exercise of capability | Hold; request through an authorized channel if appropriate |
| Representation merges relevant states | Model cannot express a useful distinction | Propose a refinement |
| A plan consumes a shared resource | Another actor's feasible options | Expose the tradeoff |
| Several operators become composable | Reachable capability under a declared budget | Test the composition |
| Only the wording changes | Description | Do not count a new capability |

An epistemic update can reveal an existing possibility without creating it physically. New authorization can make an existing mechanism exercisable without changing its physics. A newly learned macro can reduce search cost without expanding what is mathematically expressible. These are all useful changes, but they require different claims.

The “second world” is therefore a **derived, actor- and model-relative possibility structure**. It need not be a second physical realm or global truth graph. It depends on observation quality, model version, actor capability, resources, time, declared target, and local admission.

A compact proposed distinction is:

- Physical feasibility: would the mechanism work under the specified conditions?
- Estimated feasibility: does the present evidence/model support that prediction?
- Admissibility: may this actor attempt it here?
- Desirability: does it serve the relevant people's declared objectives?
- Practical reach: can the bounded search/runtime find and execute it within budget?

An opportunity claim should expose these components. One confident scalar hides too much.

### Why the residual is the bridge

The retained mismatch in 004 can become a starting point for research:

1. Preserve the frozen prediction and the supplied observation.
2. Keep several explanations live when evidence cannot separate them.
3. Find a permitted observation or sandbox intervention for which the explanations predict different results.
4. Freeze those predictions before seeing the result.
5. Update or abstain, retaining the earlier error.

This is more demanding than storing a scar. It makes the scar useful for allocating attention.

However, outcome noise, sensor failure and randomness can create endless surprise. The target should be **decision-relevant uncertainty reduced per declared cost**, compared with simple query policies. Surprise alone is not the objective.

### What the “new primitive” claim would require

At least four achievements are often hidden in that phrase:

| Achievement | Evidence needed |
|---|---|
| New name | A label; no cognitive novelty follows |
| New useful feature/predicate | Held-out prediction or planning benefit over the unrevised representation |
| New program abstraction | Search, cost or transfer benefit over direct composition under equal budgets |
| New causal variable | Additional assumptions and discriminating interventions supporting causal interpretation |

Today's MOTIF-004 selects a contextual fact from an existing vocabulary. It does not invent a new relation type. A future predicate may be valuable even when definable using existing primitives; practical abstraction can matter without extending fundamental expressivity.

The nearest ordinary explanation for the whole architecture is symbolic model learning plus planning, active query selection, and careful engineering of provenance. MOTIF must beat that explanation experimentally before claiming a distinct cognitive architecture.

## The next study: THE FIRST QUESTION

**Proposal, not a renaming of an adopted roadmap item.** This can be a precursor or bounded sub-study beside MOTIF-005.

**Hypothesis:** after a failed prediction, a learner that preserves competing explanations and chooses a discriminating query will improve held-out predictions of available actions at a lower observation cost than fixed query policies.

### Smallest honest specimen

Create two sandbox mechanisms that produce identical initial learner-visible records but differ on an accessible hidden prerequisite. The test generator and evaluator retain the ground truth separately from the learner. Use procedurally generated names and mechanisms, rather than famous stories the model may already know.

Give the learner these options:

- inspect a relevant hidden condition;
- inspect an irrelevant nuisance condition;
- request a permitted sandbox trial;
- propose a representation refinement from a bounded grammar;
- abstain.

Some cases must be unidentifiable under the permitted queries. Abstention is correct there.

Include distinguishable ground-truth families:

| Family | Deliberate condition | What should be learned or refused |
|---|---|---|
| Missing prerequisite | Relevant fact absent from the visible record | Seek the discriminating observation |
| Bad abstraction | Two concrete conditions share one coarse feature | Refine the feature, then test it |
| Spurious correlation | Color tracks success in training but breaks in intervention | Drop the color explanation |
| Mechanism shift | The environment's rule changes after training | Preserve earlier success; revise scoped model |
| Observation delay | Effect occurs after the first inspection | Report time/observation uncertainty |
| Incomplete witness | Relevant outcome unavailable | Do not label unobserved as failed |
| Admission refusal | No action attempt occurred | Preserve refusal separately from mechanism outcome |
| Unresolvable ambiguity | All permitted queries agree | Abstain without fabricated certainty |

The small starting version need only implement the first, third, seventh and eighth families. Add representation refinement only when the simpler query-selection experiment is interpretable.

### Comparisons and metrics

Compare equal-budget systems: the current 004 rule; fixed/random query choice; a simple finite hypothesis-elimination or decision-tree learner; then MOTIF's proposed policy. Add an LLM proposer only as a separate comparison with identical visible evidence.

Report per mechanism family and multiple predeclared generator seeds:

- correct prediction of available-action sets, including false positives and false negatives;
- query cost and number of attempts;
- abstention coverage and error among answered cases;
- predicted versus measured opportunity gains;
- representation size and search cost;
- unauthorized-attempt count, reported separately from predictive success;
- sensitivity to nuisance names, colors, order, and hidden evaluator information.

Use probability calibration metrics only if the model emits meaningful probabilities. Do not manufacture confidence numbers from an uncalibrated rule score.

Freeze generator splits, budgets and primary metrics before final evaluation. Stop or simplify if the basic finite learner performs equally well at lower cost. A test whose every result validates the ambition is not a discriminator.

### A concrete falsifier

The candidate fails its central performance claim if, under identical evidence and query budgets, its extra structure does not improve opportunity prediction, useful query efficiency, or interpretable transfer relative to the simple baseline. Retaining cleaner records may still be an engineering benefit; report that separately.

## Novelist's contribution: worlds that expose illegal knowledge

Novelist offers more than a source of colorful examples. Its story-control method tracks:

- what is true in the authored world;
- what a viewpoint character knows or falsely believes;
- what the reader has actually been shown;
- what inference the author expects;
- what an action changes and what that makes possible next.

This gives a useful proposed testbed for MOTIF and 3rdi.

A tiny fictional village can contain a locked workshop, a working tool, two people, a false belief, a finite deadline and one consent boundary. A character may lack knowledge of an available tool. Another may know about it but lack permission to use it. Teaching can change a skill; showing a receipt can change knowledge; a legitimate grant can change admissibility. The simulator must keep those transitions distinct.

The test asks for a predicted state and action frontier before prose is generated. A separate renderer may explain the result. Attractive narration earns no mechanical score.

Hostile cases should include a hidden ending leaking into the plan, an unseeded rescue, an unexplained new power, an agent knowing another agent's private observation, and a copied “permission granted” string.

A novel is an authored world with controlled rules. Success there validates performance in that artificial setting, not a real community's causal dynamics or people's actual preferences. Human narrative judgment is a separate measure.

## Further experiments worth keeping alive

| Candidate | Core question | Discriminator |
|---|---|---|
| Opportunity versus duplication | Did more futures appear, or just more equivalent paths? | Duplicate irrelevant actions; useful opportunity score should not inflate |
| Who gains the door? | Does one actor's new capability close another's options? | Track per-actor gains, losses, shared resources and vetoes |
| Knowledge versus world change | Did the action create a route or reveal it? | Same physical world, different exposure receipts |
| Scar transfer | Can a useful failure lesson travel without the original private history? | Fresh receiver, different mechanism, leakage probes and local admission |
| Compositional surplus | Does the assembly do anything the parts cannot independently do? | Remove one contributor and test the declared end-to-end target |
| Same state, different history | Is history necessary to predict later behavior? | Equal visible bodies with different carried resource/dependency states |
| Useful ontology | Does a new predicate improve held-out planning enough to justify complexity? | Fixed-vocabulary, redundant-predicate and nuisance-feature controls |
| Minimal intervention | Which small change opens useful routes within a real budget? | Compare cost, duration, confidence, option losses and target preferences |

These are proposals. No table entry is an implemented capability merely because an older note uses similar language.

## What survives the pressure

**Seed preserved from the user-supplied report:** “An intelligence that recognizes when one action makes entirely new actions possible.”

**Literal result:** supported only in the narrow sense that the inspected synthetic code compares available grounded rewrites before and after assumed transitions.

**What broke:** claims of learned ethics, discovered causality, new neural architecture, automatic ontology invention, real-world teaching effects, or novel status for graph reasoning are not established.

**What survived:** a testable program connecting relational transformation learning, changes in practical opportunity, explicit negative evidence, discriminating queries and bounded revision.

**Independent-domain analogy:** narrative continuity offers a controlled setting for actor-local knowledge and consequence. It is a testbed proposal, not proof of the same mechanism in physical intelligence.

**Nearest ordinary explanation:** a transparent combination of symbolic planning, active learning and evidence-preserving records.

**Next discriminator:** THE FIRST QUESTION, with an independent sandbox oracle, equal budgets, hostile ambiguity and a simple finite learner baseline.

The interesting long-term possibility is a system that learns both how to act and when its way of describing the situation is inadequate. This pass establishes a source-backed route toward testing that possibility. It does not establish the destination.
