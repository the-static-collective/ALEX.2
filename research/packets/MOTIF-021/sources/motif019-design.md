# MOTIF-019 — THE HIDDEN COMMON ANCESTOR

**Question:** Are many apparently independent observations actually descendants of one common source, or merely subject to one shared failure mechanism?

**Scope:** Executable **synthetic** research, not recovered real genealogy, authenticated source identity, causal discovery, external surveillance, autonomous improvement, or authorization for any action.

## New capability: suspected *dependency*, not assumed independence

The system receives a finite array of six *invented* reporter-carriers across matched specimens, and two separately declared reference families that label each specimen. The hidden simulator truth and literal ancestry are never given to the analyzer.

### Inferences it can support, under its assumptions

1. **Declared carrier lineage:** A reporter may explicitly declare that it forwards another carrier. The tool checks content equality on every corresponding synthetic specimen and refuses contradictory copies. A matching declaration is an **unverified provenance claim**, not authenticated ancestry.
2. **Stratified shared-error signal:** For each unordered pair of reporters, it compares binary reporting errors **conditional on the reference truth label** (yes and no tested separately). This controls the easiest spurious dependency caused merely by shifts in the prevalence of true labels.
3. **Exact conditional independence test:** The analyzer uses an exact upper-tail Fisher/hypergeometric test on each 2×2 error table. It predeclares **30 tests**: 15 source pairs × two reference strata, with conservative family-wise α=.05 Bonferroni correction. Each stratum must have at least **45** specimens; less means HOLD.
4. **Conservative genealogy-of-evidence projection:** Each declared copy and strongly co-erroneous pair can be grouped conservatively into one *potential* evidence family. Grouping is a precaution against double-counting; it is **not evidence of literal ancestry** and non-significant pairwise tests do not establish independence.
5. **Question machine:** For suspicious pairs, prepare an inert, bounded question portfolio. **First challenge the reference families with a genuinely separate independent adjudication**, then seek original-carrier custody and transfer records. These are unexecuted suggestions. Humans decide whether evidence is sufficient for any method revision.

## Key falsifications (must not disappear)

The simulator has distinct mechanisms with overlapping observational consequences:

| Synthetic world | What actually generated the reports | What a good receipt must distinguish |
| --- | --- | --- |
| Independent | Six independently noisy observers | No detected common error; **not** certified independent |
| Hidden ancestor | Two reporters share one upstream noisy carrier | Strong positive conditional error association, **not** recovered custody |
| Declared copy | One named forwarded parent with byte-identical claims | Deduplicate; declared origin remains unauthenticated |
| World shift | True yes/no base rate shifts to ~90/10 | Marginal agreement increases; stratified residual association should not |
| Shared difficulty | A sample-wise common environment makes all reporters inaccurate together | Detect a shared factor, but cannot infer literal genealogy |
| Corrupted references | Two declared reference feeds share the same bad label on some samples | **False ancestry suspicion** despite no common reporter parent |
| Weak ancestry | Genuine shared error too weak or sparse to resolve | Non-detection cannot prove independence |
| Missing or conflicting references | The purported independent reference check fails | HOLD, never silent admission |

**The important negative result:** Conditional error dependence is evidence of a shared *statistical factor*. It is generally **not identifiable as a literal common ancestor** from observational reports alone. A common environmental disturbance or a colluding reference system can produce nearly identical signals. This is not fixed by assigning more certainty to the graph.

The reference families are *declared*, not genuinely independently sourced: both originate in the local fixture generator. Even exact Fisher p-values are conditional on within-stratum independent sampling, correct references, and a predeclared test family. Correlated samples or a changed reference process can invalidate them.
