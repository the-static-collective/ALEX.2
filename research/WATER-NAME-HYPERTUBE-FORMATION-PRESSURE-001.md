# 4. Method insight: UNTRANSPORT BEFORE INTERPRETATION

When a surface has crossed expected transformations, preregister the expected inverse/normalization before looking at the residual.

```text
actual crossing T_lambda
expected untransport J
F_lambda = J o T_lambda
residual mu = F_lambda(x) - x
```

For Name research this becomes:

```text
spoken waveform
-> speaker/accent/pitch/tempo/channel transforms
-> preregistered normalization
-> residual recognized pattern
```

If the normalization/decoder is invented after seeing the favored output, mark it exploratory and require holdout replay.

### Hostile control

Use multiple speakers, languages, scripts, and non-acoustic carriers. If the supposed invariant vanishes under a carrier change that should preserve the referent, the hypothesis dies or narrows.

# 7. Method insight: REACHABILITY, NOT VIBES

When a hypothesis uses `bind`, `loose`, `gate`, `boundary`, `key`, or `constraint`, force it into a reachability test.

Let `A(G)` be the candidate reachable set.

```text

What remains invariant?
```

This converts symbolic fluency into a falsifiable topology claim.
